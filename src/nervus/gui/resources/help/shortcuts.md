# Keyboard shortcuts

On macOS use ⌘ where *Ctrl* is listed.

| Action | Shortcut |
|---|---|
| New / Open / Save | Ctrl+N / Ctrl+O / Ctrl+S |
| Save As | Ctrl+Shift+S |
| Undo / Redo | Ctrl+Z / Ctrl+Shift+Z or Ctrl+Y |
| Cut / Copy / Paste | Ctrl+X / Ctrl+C / Ctrl+V |
| Delete selection | Delete or Backspace |
| Select all | Ctrl+A |
| Create subsystem from selection | Ctrl+G |
| Auto layout | Ctrl+Shift+L |
| Up to the parent system | Ctrl+Up |
| Run simulation | Ctrl+R or F5 |
| Stop simulation | Ctrl+. |
| Simulation settings | Ctrl+E |
| Generate C code | Ctrl+B |
| Zoom in / out | Ctrl++ / Ctrl+- or Ctrl + wheel |
| Fit diagram to window | Ctrl+0 |
| Pan | Space + drag, middle mouse, or trackpad scroll |
| Help for the selected block | F1 |
| Help | Ctrl+? |
